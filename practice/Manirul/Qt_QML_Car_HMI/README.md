\# Qt QML Car HMI Dashboard



A Qt Quick and QML-based Automotive Human-Machine Interface (HMI) project that simulates an in-vehicle infotainment system and digital instrument cluster.



\## Project Overview



The application provides a multi-screen automotive dashboard interface with interactive navigation between Home, Car, Menu, Music, and Navigation screens.



\### Features



\- \*\*Home Screen:\*\* Dashboard interface with vehicle information, weather display, and climate controls.

\- \*\*Car Screen:\*\* Digital instrument cluster with speedometer and RPM visualization.

\- \*\*Menu Screen:\*\* Menu interface with application icons and interactive controls.

\- \*\*Music Screen:\*\* Music player interface using Qt Multimedia.

\- \*\*Navigation Screen:\*\* Navigation interface with route visualization and location-related functionality.

\- \*\*QML UI Components:\*\* Reusable components, properties, signals, and interactive controls.

\- \*\*C++ Integration:\*\* C++ application entry point integrated with the QML interface.

\## Prerequisites



Install the following software before building the application:



1\. \*\*Qt 6:\*\* Install a Qt version compatible with the project's `CMakeLists.txt`.

2\. \*\*Qt Creator:\*\* Recommended IDE for configuring, building, and running the project.

3\. \*\*CMake:\*\* Use the version required by the project and supported by your Qt installation.

4\. \*\*C++ compiler:\*\* Install a compatible compiler and development kit, such as MinGW or MSVC on Windows.

5\. \*\*Required Qt modules:\*\* Install the Qt modules referenced by the project, including Qt Quick, Qt Multimedia, Qt Location, and Qt Positioning, as applicable to the selected build configuration.



\## Build and Run Using Qt Creator



1\. Clone or download the repository.

2\. Open Qt Creator.

3\. Select \*\*File → Open File or Project\*\*.

4\. Browse to `Qt\_QML\_Car\_HMI/CMakeLists.txt`.

5\. Configure the project using an installed Qt 6 kit and compatible compiler.

6\. Wait for CMake configuration to finish.

7\. Click \*\*Build\*\* to compile the project.

8\. Click \*\*Run\*\* to launch the application.



\## Build Using the Command Line



Run these commands from the `Qt\_QML\_Car\_HMI` project directory in a terminal where CMake and the selected Qt kit are configured:



```bash

cmake -S . -B build

cmake --build build

```



To run the application, use the executable generated by your selected Qt kit and build configuration. The executable location and filename may vary by platform and configuration.



\*\*Note:\*\* If CMake cannot find Qt, configure `CMAKE\_PREFIX\_PATH` to point to the appropriate Qt installation. Ensure the required Qt modules and compiler are installed.



\## Troubleshooting



\- \*\*Qt package not found:\*\* Verify your Qt installation and CMake package paths.

\- \*\*Missing QML module:\*\* Install the corresponding Qt module and ensure it is available to the selected kit.

\- \*\*Multimedia playback issue:\*\* Check that the required multimedia backend and supported media codecs are available.

\- \*\*Build configuration error:\*\* Confirm that the selected compiler matches the Qt kit.

\- \*\*Runtime resource issue:\*\* Verify that the image and media resource paths used by the QML files are correct.
